# Вопросы для самопроверки
Область видимости переменной в C++ уменьшается с помощью **блоков кода** (блоков `{}`), **анонимных пространств имён** или ключевого слова `static` для глобальных переменных.

## Блоки кода
Переменные, объявленные внутри `{}` , видны только в этом блоке. Это основной способ локализации.

```cpp
void func() {
    int x = 10;  // Видна только здесь
    
    if (true) {
        int y = 20;  // Видна только в if
        // x и y доступны
    }
    // y недоступна, x доступна
}
// x и y недоступны
```

## Анонимные пространства имён
Для глобальных переменных — `(anonymous namespace)` ограничивает видимость файлом:

```cpp
namespace {  // Анонимное пространство
    int secret = 42;  // Видна только в этом .cpp файле
}

static int hidden = 100;  // Альтернатива, то же самое
```

## void,classИнициализация в условных блоках (C++17+)
Уменьшает время жизни переменной:

```cpp
void example() {
    if (int* ptr = allocate()) {  // ptr живет только в if
        use(ptr);
    }
    // ptr уже уничтожена
}
```
